# BioInfo Nexus 定时任务设置指南

本文档提供了如何设置定时任务来自动执行数据库维护操作的详细说明，包括清理未激活用户和优化数据库。

## Linux 环境设置

在 Linux 环境下，我们使用 crontab 来设置定时任务。

### 使用 crontab 设置定时任务

1. **查看当前的 crontab 配置**
   ```bash
   crontab -l
   ```

2. **编辑 crontab 配置**
   ```bash
   crontab -e
   ```
   > 注意：首次运行时可能会提示选择编辑器，推荐选择 nano 作为初学者友好的选择。

3. **添加定时任务**
   
   crontab 的基本格式如下：
   ```
   分钟 小时 日期 月份 星期 命令
   ```
   
   每个字段的取值范围：
   - 分钟：0-59
   - 小时：0-23
   - 日期：1-31
   - 月份：1-12
   - 星期：0-7（0 和 7 都表示星期日）
   
   特殊字符：
   - `*`：表示所有可能的值
   - `,`：用于分隔多个值
   - `-`：表示一个范围
   - `/`：指定间隔频率

4. **配置示例**

   以下是一些常用的配置示例：
   
   **每天凌晨 3 点执行维护任务**
   ```
   0 3 * * * /path/to/instance/maintenance_tasks.sh
   ```
   
   **每周日凌晨 2 点执行维护任务**
   ```
   0 2 * * 0 /path/to/instance/maintenance_tasks.sh
   ```
   
   **每月 1 日凌晨 1 点执行维护任务**
   ```
   0 1 1 * * /path/to/instance/maintenance_tasks.sh
   ```
   
   **每隔 6 小时执行一次维护任务**
   ```
   0 */6 * * * /path/to/instance/maintenance_tasks.sh
   ```

5. **确保脚本具有执行权限**
   ```bash
   chmod +x /path/to/instance/maintenance_tasks.sh
   ```

6. **验证 crontab 是否成功添加**
   ```bash
   crontab -l
   ```

7. **查看 cron 日志以确认任务是否执行**
   ```bash
   grep CRON /var/log/syslog
   ```
   或
   ```bash
   journalctl -u cron
   ```

### 注意事项

1. **路径问题**：在 crontab 中，应使用绝对路径而非相对路径。

2. **环境变量**：crontab 执行时的环境变量与普通终端不同，如果脚本依赖特定环境变量，应在脚本中明确设置。

3. **重定向输出**：如果需要记录任务执行的输出，可以将输出重定向到文件：
   ```
   0 3 * * * /path/to/instance/maintenance_tasks.sh >> /path/to/cron.log 2>&1
   ```

4. **邮件通知**：默认情况下，cron 会将任务的输出通过邮件发送给用户。如果不需要邮件通知，可以在 crontab 文件开头添加：
   ```
   MAILTO=""
   ```

5. **测试脚本**：在添加到 crontab 之前，建议先手动执行脚本以确保其正常工作。

### 维护任务脚本说明

`maintenance_tasks.sh` 脚本执行以下维护任务：

1. 清理验证码已过期的未激活用户
2. 清理长时间未激活的用户（超过 30 天）
3. 优化数据库（执行 VACUUM 操作）

所有操作的日志都会记录到 `maintenance_tasks.log` 文件中，方便后续查看和排查问题。
