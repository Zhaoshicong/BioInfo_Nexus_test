## 1. 服务器配置选择

### 🚀 推荐配置
- **CPU**: 4核心（最低推荐）
- **内存**: 4GB RAM（最低推荐）
- **带宽**: 4Mbps（最低推荐）
- **系统**: Ubuntu 20.04/22.04 LTS
- **硬盘**: 40GB SSD（系统盘）

### 💡 为什么选择4核4G4M？
```bash
# 生物信息学应用特点：
- 蛋白质序列分析计算密集
- AI服务调用需要稳定网络
- 密码子数据库文件多（35796个文件）
- 支持多用户并发访问
- MySQL数据库操作频繁
```

## 5. MySQL数据库配置

### 🗄️ 创建数据库和用户
```sql
-- 1. 连接MySQL
mysql -u root -p

-- 2. 创建数据库
CREATE DATABASE bioinfo_nexus CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 3. 创建专用用户
CREATE USER 'kean'@'%' IDENTIFIED BY 'your_strong_password_here';

-- 4. 授权
GRANT ALL PRIVILEGES ON bioinfo_nexus.* TO 'kean'@'%';
FLUSH PRIVILEGES;

-- 5. 验证用户
SELECT user, host FROM mysql.user WHERE user = 'kean';

-- 6. 退出
EXIT;
```

### 🔗 配置远程连接
```bash
# 1. 编辑MySQL配置文件
sudo vim /etc/mysql/mysql.conf.d/mysqld.cnf

# 2. 修改bind-address（允许外部连接）
# 找到这行：bind-address = 127.0.0.1
# 改为：bind-address = 0.0.0.0

# 3. 重启MySQL服务
sudo systemctl restart mysql

# 4. 检查端口监听
netstat -tulnp | grep 3306
```

## 8. Nginx配置

### 🌐 配置Nginx站点
```nginx
# 编辑Nginx配置文件
# 在宝塔面板中：网站 -> 设置 -> 配置文件

server {
    listen 80;
    server_name your_domain.com;  # 替换为你的域名或IP
    root /www/wwwroot/default/BioInfo_Nexus_test/front_html;
    index index.html index.htm;
    
    # 日志配置
    access_log /www/wwwlogs/bioinfo_nexus_access.log;
    error_log /www/wwwlogs/bioinfo_nexus_error.log;
    
    # 文件上传大小限制
    client_max_body_size 16M;
    
    # 静态文件服务
    location / {
        try_files $uri $uri/ /index.html;
        
        # 静态资源缓存
        location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
            expires 1y;
            add_header Cache-Control "public, immutable";
        }
    }
    
    # API请求代理到Flask应用
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # 超时配置
        proxy_connect_timeout 300s;
        proxy_send_timeout 300s;
        proxy_read_timeout 300s;
        
        # 缓冲区配置
        proxy_buffering on;
        proxy_buffer_size 8k;
        proxy_buffers 8 8k;
    }
    
    # 管理员后台代理
    location /admin/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
    
    # 临时文件访问
    location /temp/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        
        # 临时文件较大，增加超时时间
        proxy_read_timeout 600s;
    }
    
    # 阻止恶意请求（防止日志噪音）
    location ~ /(php-cgi|boaform|cgi-bin|\.php$) {
        deny all;
        return 444;  # 直接关闭连接
    }
    
    # 隐藏敏感文件
    location ~ /\.(env|git|htaccess|htpasswd) {
        deny all;
        return 404;
    }
    
    # Gzip压缩
    gzip on;
    gzip_vary on;
    gzip_comp_level 6;
    gzip_types
        text/plain
        text/css
        text/xml
        text/javascript
        application/javascript
        application/xml+rss
        application/json;
}
```

## 14. 备份策略

### 💾 数据库备份
```bash
# 创建备份脚本
vim /www/wwwroot/default/BioInfo_Nexus_test/backup_db.sh
```

```bash
#!/bin/bash
# backup_db.sh - 数据库备份脚本

BACKUP_DIR="/www/backup/database"
DATE=$(date +%Y%m%d_%H%M%S)
DB_NAME="bioinfo_nexus"
DB_USER="kean"
DB_PASS="your_password"

# 创建备份目录
mkdir -p $BACKUP_DIR

# 备份数据库
mysqldump -u $DB_USER -p"$DB_PASS" $DB_NAME > $BACKUP_DIR/bioinfo_nexus_$DATE.sql

# 压缩备份文件
gzip $BACKUP_DIR/bioinfo_nexus_$DATE.sql

# 删除7天前的备份
find $BACKUP_DIR -name "*.sql.gz" -mtime +7 -delete

echo "数据库备份完成: bioinfo_nexus_$DATE.sql.gz"
```
